# Codex Paper Reader

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**和 Agent 一起讀論文，留下理解，而不只是 PDF。**

輕量的文獻工作流程 Skill，協助你討論論文、管理來源、製作個人化 HTML 筆記及撰寫文獻回顧。搭配 Zotero、瀏覽器或慣用的 PDF 閱讀器使用。使用 Codex 開發與維護。

## 🚀 快速開始

**1. 請 Codex 幫你安裝**

```text
幫我安裝這個 Skill：https://github.com/hwang847/codex-paper-reader.git
```

**2. 在 Codex 中開啟論文資料夾**

選擇一個本機目錄，然後說：

```text
使用 $literature-workflow，幫我設定這個資料夾的論文閱讀環境。
```

Codex 會檢查環境，必要時簡單詢問你的閱讀目標、語言與歸檔偏好，保留既有檔案與指令，並將確認的偏好記入本機 `AGENTS.md`。設定後會告訴你檔案放在哪裡、哪些功能已就緒、還有哪些未完成，以及如何開始閱讀。Python 和 PDF 工具也可交給 Codex 協助設定，不必事先準備；偏好隨時可以透過對話調整。

**3. 放入 PDF，開始討論**

保留 `2508.05002v1.pdf` 這類下載檔名即可。從閱讀器複製論文標題：

```text
帶我閱讀這篇論文：<複製的標題>
從實作角度說明它的方法流程。
現在根據我們的討論製作 HTML 筆記。
```

Codex 透過標題索引找到本機 PDF，你不需要手動改名或維護索引。掃描檔、特殊排版或同名文獻可能需要補充路徑或修正標題。

## ✨ 可以幫你做什麼

| 你提出需求 | Codex 與 Skill 協助你完成 |
| --- | --- |
| 「結合我的研究方向說明。」 | 依你的深度偏好閱讀、翻譯與討論，需要時深入實驗與附錄。 |
| 「把我們釐清的重點記下來。」 | 製作精簡、因文而異的 HTML 筆記，附來源連結與論文插圖截圖；後續理解改變時更新同一份筆記。 |
| 「整理新加入的論文。」 | 預覽依標題重新命名與分類的結果，再歸檔 PDF，不覆寫同名檔案，並維護已管理的引用連結。 |
| 「這個程式碼儲存庫對應那篇論文。」 | 將 PDF、arXiv、DOI、程式碼與技術文件關聯為同一閱讀對象的多個來源。 |
| 「比較這些文獻，協助我的文獻回顧。」 | 維護選定的文獻範圍、比對證據，並在你要求時撰寫綜述。 |

筆記在你提出要求後製作，不會每次回答都新增一份。自動歸檔須啟用，在 Codex 呼叫工作流程時執行，沒有背景監聽。你的本機檔案始終是主要副本。

## 🎯 按你的方式使用

直接告訴 Codex：

```text
我正在寫文獻回顧，更關注每篇論文如何定位自己與既有工作的關係。
以論文寫作為目的閱讀時，要包括實驗設計與相關附錄。
請將這些偏好記在目前工作區的 AGENTS.md 中。
```

語言、筆記風格、分類方式與閱讀流程，都可以透過對話調整。既有文獻庫不必強行遷移到新的目錄結構。

新工作區通常使用 `papers/`、`notes/`（圖片放在 `notes/assets/`）、`references/` 與 `surveys/`。新 PDF 放在工作區根目錄，請 Codex 整理或啟用自動歸檔偏好即可。

## 🔌 選用工作連接器

想將研究成果用於其他服務？直接告訴 Codex，例如：

```text
幫我將這個工作區連接到飛書，用來歸檔選定的筆記。
在 GitHub 上找合適的 CLI，協助安裝，並在這個專案中統一管理設定。
```

Codex 會確認工具來源與相容性，在授權後協助安裝及登入，並將用法記錄在工作區的 `connectors/README.md`（或既有設定說明）中。飛書/Lark 只是一個例子，其他服務可依可用工具擴充。不預先安裝、不自動同步，也不影響你只在本機讀論文、做筆記。

## 能力範圍與相容性

Skill 提供精簡工作流程與可靠的本機工具，**推理與寫作交給宿主 Agent**。它不是 PDF 閱讀器、無人值守的研究服務或通用聊天機器人。繼續使用你慣用的閱讀器，並選擇想研究的來源；Skill 本身不需要模型 API Key 或專用伺服器。

採用標準 `SKILL.md`，輔助指令碼需要 Python 3.9+，以 Codex 為主要使用環境。其他支援 Skill、本機檔案及指令執行的 Agent 也可重用，安裝方式與工具權限由宿主決定。PDF 擷取與渲染依賴選用工具，需要時由 Codex 協助安裝。

安全檔案移動依賴 POSIX 介面，適用於 macOS/Linux；Windows 請使用 WSL，暫不支援原生 Windows 歸檔。
