# Codex Paper Reader

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

**エージェントと論文を読む。PDFだけでなく、理解も残す。**

論文の議論、出典管理、自分に合った HTML ノートの作成、文献レビューを支援する軽量な Skill です。Zotero、ブラウザーなど、普段の PDF リーダーと併用できます。Codex を使って開発・保守しています。

## 🚀 クイックスタート

**1. Codex にインストールを頼む**

```text
この Skill をインストールして：
https://github.com/hwang847/codex-paper-reader.git
```

**2. 論文フォルダーを Codex で開く**

任意のローカルフォルダーを選び、次のように伝えます。

```text
$literature-workflow を使って、このフォルダーに論文を読むための環境を整えて。
```

Codex が環境を確認し、必要に応じて読む目的、言語、ファイル整理の好みを簡単に尋ねます。既存のファイルや指示を保持し、確認した好みをローカルの `AGENTS.md` に記録します。設定後は、ファイルの保存先、使える機能、未完了の項目、読み始め方を案内します。Python や PDF ツールの準備も Codex に相談できるので、事前の設定は不要です。好みは後から対話で変更できます。

**3. PDF を入れて、対話を始める**

`2508.05002v1.pdf` のようなダウンロード時のファイル名で構いません。リーダーから論文タイトルをコピーします。

```text
この論文を一緒に読んで：<コピーしたタイトル>
自分で実装できるように、手法の流れを説明して。
ここまでの議論を基に HTML ノートを作って。
```

Codex がタイトルの索引から対応するローカル PDF を探します。手動で名前を変えたり、索引を管理したりする必要はありません。スキャン文書、特殊なレイアウト、紛らわしいタイトルでは、パスの指定やタイトルの修正が必要な場合があります。

## ✨ できること

| あなたの依頼 | Codex と Skill の支援 |
| --- | --- |
| 「私の研究テーマに結びつけて説明して」 | 希望する深さで読み解き、翻訳し、議論します。必要に応じて実験や付録も扱います。 |
| 「議論で整理できたことを残して」 | 出典リンクや論文の図のスクリーンショットを含む、簡潔で論文ごとの HTML ノートを作成。理解が変わったら同じノートを更新します。 |
| 「新しい論文を整理して」 | タイトルに基づく命名と分類をプレビューし、同名ファイルを上書きせずに整理。管理対象のリンクも更新します。 |
| 「このコードはあの論文のもの」 | PDF、arXiv、DOI、コード、技術文書を、一つの読み物に関連する出典としてまとめます。 |
| 「これらの論文を比較してレビューに役立てたい」 | 対象文献を管理し、根拠を比較。依頼に応じてレビュー本文を作成します。 |

ノートは依頼時に作成し、回答のたびに新規作成はしません。自動整理は任意で有効にでき、Codex がワークフローを実行するときに動作します。バックグラウンド監視は行いません。ローカルファイルが常に主となるコピーです。

## 🎯 自分に合わせる

好みは、そのまま Codex に伝えてください。

```text
文献レビューを書いているので、各論文と先行研究の関係を重視して。
論文執筆のために読むときは、評価設計と関連する付録も扱って。
この好みをワークスペースの AGENTS.md に記録して。
```

言語、ノートのスタイル、分類、読み進め方は対話で調整できます。既存の文献フォルダーを新しい構成に移す必要はありません。

新しいワークスペースでは通常、`papers/`、`notes/`（画像は `notes/assets/`）、`references/`、`surveys/` を使います。新しい PDF はルートに置き、整理を頼むか、自動整理の設定を伝えてください。

## 🔌 外部サービスとの連携（任意）

研究成果を他のサービスでも使いたいときは、Codex に伝えてください。例えば：

```text
選んだノートを保存できるように、このワークスペースを Feishu と連携させて。
GitHub で適切な CLI を探して導入を手伝い、設定をこのプロジェクトでまとめて管理して。
```

Codex がツールの提供元と互換性を確認し、許可を得てインストールやログインを支援します。使い方はワークスペースの `connectors/README.md`（または既存の設定メモ）に記録します。Feishu/Lark は一例で、他のサービスも利用可能なツールに応じて追加できます。事前インストールや自動同期はなく、論文の閲読やノート作成に外部連携は不要です。

## 対応範囲と互換性

Skill が提供するのは小さなワークフローと信頼できるローカルツールです。**推論と執筆はホストのエージェントが担当します。** PDF リーダー、無人で動く研究サービス、汎用チャットボットではありません。普段のリーダーと併用し、調べたい資料を選んでください。Skill 自体にモデルの API キーや専用サーバーは不要です。

標準の `SKILL.md` を採用し、補助スクリプトには Python 3.9+ が必要です。主な対象は Codex です。他の Skill 対応エージェントでも、ローカルファイルとコマンド実行に対応していれば再利用できます。インストール方法やツールの権限はホストによります。PDF のテキスト抽出・描画に必要な追加ツールは、必要になった時点で Codex に導入を手伝ってもらえます。

安全なファイル移動には POSIX API を使います。macOS/Linux、または Windows の WSL を利用してください。Windows ネイティブ環境でのファイル整理には未対応です。

すでに `~/.codex/skills` などの対応パスにインストール済みなら、変更を保持したままそのコピーを更新するよう Codex に頼んでください。重複インストールは避けます。Skill が認識されない場合は Codex のセッションを再起動してください。
